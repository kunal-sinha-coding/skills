# Repository Notes

## 2026-09-02: Create hill-climbing skill

Added `hill-climbing/SKILL.md` and its UI metadata to provide a controlled, iterative training-debugging workflow. The skill defaults to a stable ten-example evaluation batch, creates a timestamped dedicated branch, reads the repository’s documented command and log schema, classifies every failure, records root-cause analysis and one-fix experiments in `hillclimbing.txt`, and compares each subsequent run against the same task IDs. The skill was validated with the bundled skill validator.
